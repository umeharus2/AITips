# AI Tips Weekly — 税理士事務所のための毎週10分AI講座

毎週10分、事務所メンバー向けにAI活用Tipsを紹介するためのスライド置き場です。
スライドはすべてブラウザで動く単一HTMLファイルで、Claude(claude.ai/code)に頼んで毎週作ります。

## 毎週の流れ(これだけ覚えればOK)

1. **claude.ai/code でこのリポジトリのセッションを開く**
2. **こう頼む**(コピペ用):

   > 今週の分を作って。テーマは topics.md から選んで提案して。

   テーマを自分で決めたいときは:

   > 今週の分を作って。テーマは「◯◯◯」で。

3. Claudeが `vols/volN.html` を作り、`index.html`(一覧)と `topics.md`(ネタ帳)を更新してプッシュします
4. **中身を確認して、直したいところがあればそのままチャットで指示**(「3枚目の例をもっと初心者向けに」など)
5. 発表当日はブラウザでスライドを開いて画面共有するだけ

作り方のルール(スライドの型・文体・チェックリスト)は `CLAUDE.md` に書いてあり、Claudeは毎回それを読んでから作業します。ルールを変えたくなったら CLAUDE.md を直接編集するか、Claudeに「CLAUDE.mdのルールをこう変えて」と頼んでください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | バックナンバー一覧(GitHub Pagesのトップページ) |
| `vols/vol1.html` 〜 | 各回のスライド本体 |
| `template/slide-template.html` | 新しい回の雛形(直接使うことはない) |
| `topics.md` | ネタ帳。1年分以上のトピック案と消化状況 |
| `CLAUDE.md` | Claudeへの作業指示書(スライドの型・品質ルール) |

## GitHub Pages の設定(最初に1回だけ)

所内にURLひとつで共有するための設定です。

1. このリポジトリは現在**プライベート**です。GitHub無料プランではプライベートリポジトリでPagesが使えないため、**リポジトリを公開(Public)にする**必要があります
   - GitHubの `Settings` → `General` → 最下部 `Danger Zone` → `Change visibility` → `Make public`
   - ※公開＝インターネット上の誰でも見られる状態になります。顧問先名などの機密情報をスライドに載せない運用を徹底してください(CLAUDE.mdにもルール化済み)
   - どうしても非公開にしたい場合は、GitHub Pro(月4ドル程度)に加入するとプライベートのままPagesが使えます
2. `Settings` → `Pages` → `Build and deployment` → Source を `Deploy from a branch` にし、Branch でメインで使うブランチと `/ (root)` を選んで Save
3. 数分待つと `https://umeharus2.github.io/AITips/` で一覧ページが見られるようになります。このURLを事務所のチャット等に貼っておけば、以後は毎週自動で最新版が反映されます

※ Pagesを使わない場合でも、`vols/volN.html` は1ファイルで完結しているので、メールやチャットでファイルをそのまま配布できます。

## 10分発表のコツ(目安の時間配分)

- **0〜2分**: つかみ。「こういう作業、時間かかってませんか?」
- **2〜7分**: Tips紹介。可能なら1つは**その場でライブ実演**(ChatGPTに実際に打って見せる)。実演が一番伝わります
- **7〜9分**: プロンプト集の紹介。「このページのカードをクリックするとコピーできます」
- **9〜10分**: 今週の宿題。「来週、やってみてどうだったか教えてください」

発表後に出た質問・要望は `topics.md` の「リクエスト・持ち込みネタ」に足しておくと、次回以降のネタになります(Claudeに「topics.mdに追加しといて」と頼むだけでもOK)。

## スライドの操作方法

- `←` `→` キー、または画面下のボタンでページ送り
- スマホではスワイプで送れます
- プロンプト集のカードはクリックでクリップボードにコピーされます

Chatでもできる。
Workなら、仕事の流れごと任せられる

レシート画像のCSV化から、複数資料の照合・確認事項の整理まで。今日は違いを2つの実演で見比べます。

← → キーまたはクリックで進む

最初に、正直に

レシートをCSVにするだけなら、普通のChatでもできます

  • 画像を読み取る — 日付・金額・支払先などを抽出
  • 表に整理する — 指定した列に並べる
  • CSVを作る — ダウンロードできる形で返す
今日のテーマ

Workの価値は「CSVを作れること」ではありません。どこまで仕事をまとめて任せられるかです。

01

ChatとWork、違いはどこ?

CHAT — ひとつの作業を一緒に進める
質問、相談、要約、表づくりなどをその場で実行。次に何をするかは人が順番に指示する。
WORK — 仕事のまとまりを任せる
ゴール・材料・完成条件を渡すと、複数の手順を組み立て、確認しながら完成まで進める。
覚えるのはこれだけ

違いは「作れるもの」ではなく、「任せられる仕事の長さと範囲」。

02

AIエージェント = 考える・道具を使う・確認するAI

  • ① ゴールを理解して、作業を分ける — 何から始めるかを考える
  • ② ファイルやアプリなどの道具を使う — 必要な情報を集めて処理する
  • ③ 結果を確認し、足りなければやり直す — 最後に完成物を返す
「何でも自動で正しくやるAI」ではありません

人がゴール・触れてよい範囲・確認ポイントを決めることで、仕事として使えるようになります。

03

エージェントは、途中の工程をつなげる

ゴール: レシートとカード明細から、記帳前の確認資料を完成させる

  • 読み取る → 整理する — レシートと明細をそれぞれ表にする
  • 照合する → 不明点を分ける — 金額・日付を比べ、合わないものを抽出
  • 成果物を作る — CSV、不一致一覧、質問リストをまとめる

ひとつひとつはChatでもできます。一連の流れとして任せるのがWorkです。

実演 1 — CHAT

レシート画像を、CSVにする

  • ① 私物のレシート画像を添付 — 複数枚でも処理できます
  • ② 欲しい列とルールを指示 — 不明は「要確認」、科目は候補まで
  • ③ CSVを受け取り、件数・日付・金額を確認
Chatが得意な仕事

画像の枚数ではなく、1回の依頼で完結する単発作業。ここまでは普段のChatで十分です。

実演 2 — WORK

複数資料から、確認作業までまとめて任せる

材料: ダミーのレシート5枚 + ダミーのカード利用明細

  • ① 仕訳候補CSV — 読み取った情報と科目候補
  • ② 一致しない項目の一覧 — 明細との不一致・重複・不足
  • ③ 人に確認する質問リスト — 判断できない点を推測せず分離
実演中の見どころ

開始したら待たずに次のスライドへ。AIが作業中に、人は別の仕事へ進めるところも違いです。

税理士事務所でWorkが向くのは、工程がつながる仕事

  • 前期・当期の複数資料 → 増減箇所、確認事項、顧問先への質問案
  • 面談の文字起こし + 関連資料 → 議事録、宿題一覧、お礼メール案
  • 複数の証憑 + 利用明細 → 入力候補、重複・不足一覧、検算結果

目印は、複数の材料・複数の手順・複数の完成物があることです。

Workは、正解率を上げるモードではありません

変わること
・任せられる工程が長くなる
・使う材料や道具が増える
・複数の完成物を作りやすくなる
変わらないこと
・読み間違いや判断ミスはあり得る
・科目や税区分の確定は人が行う
・数字と根拠は人が検算する
役割分担

AIは下ごしらえ・候補・確認事項の整理。最終判断と提出前確認は人の仕事です。

大事な注意点

任せる範囲は、人が決める

  • 利用するデータは、各社・事務所のルールに従う
  • 接続するファイルやアプリは、必要なものだけに絞る
  • 重要な操作と完成物は、内容を確認してから使う
実演・練習について

今日は私物またはダミーの資料を使用。顧問先データを扱う場合は、所属先のルールに沿って判断してください。

コピペで使える — Chat版とWork版

Chat: レシート画像をCSVにする
添付したレシート画像から、下ごしらえ用CSVを作ってください。 列: 日付 / 金額(税込) / 支払先 / 摘要 / 勘定科目の候補 / 要確認メモ 不明な箇所は推測せず「要確認」、科目は候補にとどめ、最後に件数と金額合計を付けてください。
Work: 照合と確認事項までまとめて任せる
【ゴール】添付したレシート画像とカード利用明細を照合し、記帳前の確認資料を作る。 【完成物】①仕訳候補CSV ②不一致・重複・不足の一覧 ③人に確認する質問リスト 【確認】件数と金額合計を検算し、明細と一致しない項目を分ける。 【ルール】不明点は推測せず「要確認」。科目は候補まで。大きな判断が必要なら進める前に確認する。

頼み方の型: ゴール / 材料 / 完成物 / 検算 / 確認してほしいこと / 完了条件

Chatは、ひとつの作業を一緒に。
Workは、仕事のまとまりを任せる。

まずは小さな仕事で、「どこまで任せるか」を試してみる。
